Test d'intrusion Web — DVWA (OWASP Top 10)

Rapport

Rapport de test d'intrusion applicatif complet sur DVWA (configuration Low), aligné sur l'OWASP Top 10 2021. 12 vulnérabilités identifiées et exploitées — dont 4 critiques menant à la compromission totale du serveur — chacune documentée avec preuve de concept, code source vulnérable et correctif détaillé.

Points forts :

  • Injection de commandes OS & SQLi → RCE et extraction complète de la base
  • Upload de webshell PHP → reverse shell TTY interactif (netcat / socat)
  • XSS réfléchi, stocké & DOM-based, CSRF, LFI, identifiants de session faibles
  • Chaque faille scorée CVSS, avec recommandation et code corrigé

Test d'intrusion Active Directory — Compromission de domaine

Rapport

Compromission de bout en bout d'un contrôleur de domaine Windows Server 2019 (Active Directory), de la reconnaissance jusqu'au contrôle total du domaine. Une méthodologie offensive complète, documentée étape par étape, avec analyse technique et leçons défensives à chaque phase.

Chaîne d'attaque :

  • Reconnaissance & énumération : Nmap, enum4linux, RID cycling, Kerbrute
  • AS-REP Roasting → cassage de hash hors-ligne avec Hashcat
  • Mouvement latéral : partage SMB, identifiants en Base64, énumération LDAP
  • Escalade finale : DCSync + Pass-the-Hash (Evil-WinRM) → Domain Admin
Active Directory Kerberos Impacket NetExec Hashcat Evil-WinRM
